# FrameNote Backend API Plan

## Current API inventory

| Endpoint | Method | Used by frontend? | How real is it |
|---|---|---|---|
| /health | GET | Not called by any page (infra/monitoring only) | Real, trivial |
| /users/me | GET | login, signup, TopNav, upgrade | Real DB read, but "auth" trusted an X-User-Email header with no password check |
| /jobs | POST | welcome, workspace/create | Real - creates job row, queues Celery task (or runs inline if no broker) |
| /jobs | GET | home, operations, analyzing, history, insights | Real |
| /jobs/{id} | GET | analyzing (poll), insights (poll) | Real |
| /jobs/{id}/pdf | POST | insights | Real (reportlab) |
| /billing/checkout-session | POST | upgrade | Real if Stripe keys set; else returns hardcoded success URL |
| /billing/webhook | POST | Called by Stripe, not frontend | Real webhook handling (upgrade/downgrade tier) |
| /uploads/presign | POST | workspace/create | Real - R2 presign if configured, else local mock upload URL |
| /uploads/mock/{key} | PUT | workspace/create (direct fetch) | Real local fallback storage |
| /assets/{key} | GET | insights (pdf link/img) | Real FileResponse |

## Fake/mock parts previously hiding behind "real" endpoints
- Auth: any `X-User-Email` header worked, no password verification at all (fixed in Phase 1).
- Billing checkout: hardcoded success URL if Stripe keys unset (unchanged, documented behavior).
- AI summary/key points: hardcoded fallback content if `OPENAI_API_KEY` unset (unchanged so far).
- No subscription quota enforcement (planned Phase 2).

## Build phases
1. **Real authentication** (implemented) - password hashing, JWT login/signup, forgot/reset password, `Authorization: Bearer` token replaces header-only trust.
2. **Subscription quota enforcement** (planned) - limit free-tier jobs/month, surface usage in `/users/me`.
3. **Operations page real data** (planned) - real Speakers/Mentions/Shared files APIs instead of hardcoded UI lists.
4. **Polish/hardening** (planned) - rate limiting, upload size limits, job retry logic.
5. **AI provider cost optimization** (in progress) - Groq Whisper transcription implemented (`GROQ_API_KEY`, long audio auto-chunked under the 25 MB limit), with automatic fallback to local Whisper (`ENABLE_LOCAL_WHISPER`, dev only - blocked in production), then OpenAI, then Gemini; Gemini for summaries/chat.

## Hosting & deployment (decided)
Managed platforms only, no VM/Kubernetes:
- Frontend: Cloudflare Pages (free, no bandwidth limit; app has no server-side Next.js features)
- Backend API + Celery worker + Redis: Railway, starting on Hobby plan (~$5/month)
- Database: Neon (serverless Postgres, scale-to-zero)
- File storage: Cloudflare R2 (free tier, zero egress fees)
- Estimated cost at current scale: ~$5-20/month

## Pricing (decided)
Single source of truth: `backend/app/services/plans.py` (catalog copy) and `TIER_QUOTAS` in `backend/app/services/usage.py` (enforced limits).

| | Free Starter | Solo Pro |
|---|---|---|
| Price | $0 | $12/month, or $8/month billed annually ($96/year) |
| Uploaded/linked video | 1 hour/month, max 30 min per video | 15 hours/month, max 2 hours per video |
| YouTube caption notes | 3/month | Unlimited |
| Summary + key moments | Yes | Yes |
| Detailed analysis | Preview (overview + first section, locked counts) | Full |
| Ask this video | 3 per video, 10/month | 300/month |
| PDF export | Watermarked summary | Clean summary + detailed |

The full analysis is generated for every job; `analysis_for_viewer` in `services/jobs.py` trims it per viewer (API and video chat), so upgrading unlocks existing videos without reprocessing.
Stripe: create Pro prices of $12/month and $96/year and set `STRIPE_PRICE_ID_PRO_MONTHLY` / `STRIPE_PRICE_ID_PRO_ANNUAL`.

@router.post("/auth/signup", response_model=TokenResponse)
def signup(payload: SignupRequest, request: Request, db: Session = Depends(get_db)) -> TokenResponse:
    check_rate_limit("signup-ip", request_ip(request), 5, 3600)
    if settings.environment == "production" and payload.email.strip().lower() == "demo@framenote.local":
        raise HTTPException(status_code=400, detail="This email is unavailable")
    try:
        user = signup_user(db=db, email=payload.email, password=payload.password, full_name=payload.full_name)
    except ValueError as exc:
        raise HTTPException(status_code=409, detail=str(exc)) from exc
    return _token_response(user=user, db=db)

def login(payload: LoginRequest, request: Request, db: Session = Depends(get_db)) -> TokenResponse:
    check_rate_limit("login-ip", request_ip(request), 30, 900)
    check_rate_limit("login-account", payload.email.strip().lower(), 10, 900)
    user = authenticate_user(db=db, email=payload.email, password=payload.password)
    if not user or (settings.environment == "production" and user.email == "demo@framenote.local"):
        raise HTTPException(status_code=401, detail="Invalid email or password")
    return _token_response(user=user, db=db)

@router.patch("/jobs/{job_id}", response_model=JobCreateResponse)
def update_job_notes(
    job_id: str,
    payload: JobNotesUpdateRequest,
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
) -> JobCreateResponse:
    job = get_job_or_404(db=db, job_id=job_id, owner_id=current_user.id)
    if job.status != "completed":
        raise HTTPException(status_code=409, detail="Only completed notes can be edited")
    if payload.summary is None and payload.decisions is None and payload.action_items is None:
        raise HTTPException(status_code=422, detail="Provide at least one notes field")
    # Free users only see a preview, so saving these would overwrite analysis they cannot see.
    if (payload.decisions is not None or payload.action_items is not None) and not user_is_pro(db, current_user.id):
        raise HTTPException(status_code=403, detail="Editing decisions and action items requires Solo Pro.")

    analysis = get_job_analysis(job) or {}
    if payload.summary is not None:
        summary = payload.summary.strip()
        if not summary:
            raise HTTPException(status_code=422, detail="Summary cannot be empty")
        job.summary = summary
        analysis["overview"] = summary
    for field in ("decisions", "action_items"):
        raw_items = getattr(payload, field)
        if raw_items is None:
            continue
        cleaned = [item.strip() for item in raw_items]
        if any(not item or len(item) > 500 for item in cleaned):
            raise HTTPException(status_code=422, detail=f"{field} entries must be 1–500 characters")
        analysis[field] = cleaned
        if field == "action_items":
            existing_details = analysis.get("action_item_details") or []
            analysis["action_item_details"] = [entry for entry in existing_details if isinstance(entry, dict) and entry.get("title") in cleaned]
            job.custom_action_items_json = "[]"
            job.completed_action_items_json = "[]"
    job.analysis_json = json.dumps(analysis)
    # A previously generated PDF contains the old text. The next export must regenerate it.
    job.pdf_asset_key = None
    db.commit()
    db.refresh(job)
    return to_job_response(job)

@router.post("/jobs/{job_id}/clips", response_model=JobClipResponse, status_code=201)
def create_job_clip(job_id: str, payload: JobClipRequest, db: Session = Depends(get_db), current_user: User = Depends(get_current_user)) -> JobClipResponse:
    job = get_job_or_404(db=db, job_id=job_id, owner_id=current_user.id)
    if job.status != "completed":
        raise HTTPException(status_code=409, detail="Clips can be saved after processing completes")
    title = payload.title.strip()
    if not title or payload.end_seconds <= payload.start_seconds:
        raise HTTPException(status_code=422, detail="Clip needs a title and a positive time range")
    duration = job_duration_seconds(job)
    if duration and payload.start_seconds >= duration:
        raise HTTPException(status_code=422, detail="Clip must start within the recording")
    clip = JobClip(job_id=job_id, title=title, start_seconds=payload.start_seconds, end_seconds=payload.end_seconds)
    db.add(clip)
    db.commit()
    db.refresh(clip)
    return _clip_response(clip)

_RANGE_RE = re.compile(r"bytes=(\d+)-(\d*)")
_RANGE_CHUNK_SIZE = 1024 * 1024


def _serve_file_with_optional_range(path: Path, request: Request) -> Response:
    """Serve a file, honoring an HTTP Range header so <video> seeking works."""
    file_size = path.stat().st_size
    content_type = mimetypes.guess_type(str(path))[0] or "application/octet-stream"

    range_header = request.headers.get("range")
    match = _RANGE_RE.match(range_header) if range_header else None
    if not match:
        return FileResponse(path, media_type=content_type, headers={"Accept-Ranges": "bytes", "Cache-Control": "private, no-store", "Referrer-Policy": "no-referrer"})

    start = int(match.group(1))
    end = int(match.group(2)) if match.group(2) else file_size - 1
    start = max(0, min(start, file_size - 1))
    end = max(start, min(end, file_size - 1))
    length = end - start + 1

    def iter_range():
        with path.open("rb") as handle:
            handle.seek(start)
            remaining = length
            while remaining > 0:
                chunk = handle.read(min(_RANGE_CHUNK_SIZE, remaining))
                if not chunk:
                    break
                remaining -= len(chunk)
                yield chunk

    headers = {
        "Content-Range": f"bytes {start}-{end}/{file_size}",
        "Accept-Ranges": "bytes",
        "Content-Length": str(length),
        "Cache-Control": "private, no-store",
        "Referrer-Policy": "no-referrer",
    }
    return StreamingResponse(iter_range(), status_code=206, media_type=content_type, headers=headers)

        "Accepts any public video link - a YouTube/Vimeo/Loom video page, or a direct link to a "
        "video or audio file - and starts the same background pipeline the upload flow uses.\n\n"
        "Only the audio is ever fetched, and for YouTube the published captions are used when "

    db.add(subscription)
    db.commit()
    return user


def sign_in_with_verified_email(db: Session, email: str, full_name: str | None = None) -> User:
    """Find or create the account for an email address an identity provider has verified.

    An existing account whose address was never verified may have been pre-registered by someone
    who doesn't own the inbox, so its password is removed and its sessions are revoked before the
    verified owner takes it over.
    """
    normalized = email.strip().lower()
    user = db.scalar(select(User).where(User.email == normalized))
    if not user:
        user = User(email=normalized, full_name=full_name, email_verified=True)
        db.add(user)
        db.commit()
        db.refresh(user)
        db.add(Subscription(user_id=user.id, tier="free", status="active"))
        db.commit()
        return user

    if not user.email_verified:
        if user.password_hash:
            user.password_hash = None
            user.sessions_revoked_at = datetime.now(timezone.utc)
        user.email_verified = True
        db.add(user)
        db.commit()
        db.refresh(user)
    return user


def access_token_revoked(user: User, issued_at: int) -> bool:
    revoked_at = user.sessions_revoked_at
    if revoked_at is None:
        return False
    if revoked_at.tzinfo is None:
        # SQLite drops tzinfo; values are always written in UTC.
        revoked_at = revoked_at.replace(tzinfo=timezone.utc)
    # JWT iat has whole-second precision, so compare at that precision.
    return issued_at < int(revoked_at.timestamp())

def hash_password(password: str) -> str:
    return bcrypt.hashpw(password.encode("utf-8"), bcrypt.gensalt()).decode("utf-8")


def verify_password(password: str, password_hash: str) -> bool:
    try:
        return bcrypt.checkpw(password.encode("utf-8"), password_hash.encode("utf-8"))
    except ValueError:
        return False


def _create_token(user_id: str, token_type: str, expires_minutes: int) -> str:
    now = datetime.now(timezone.utc)
    payload = {
        "sub": user_id,
        "type": token_type,
        "iat": now,
        "exp": now + timedelta(minutes=expires_minutes),
    }
    return jwt.encode(payload, settings.jwt_secret_key, algorithm=settings.jwt_algorithm)


def _decode_token_payload(token: str, expected_type: str) -> dict:
    try:
        payload = jwt.decode(token, settings.jwt_secret_key, algorithms=[settings.jwt_algorithm])
    except jwt.PyJWTError as exc:
        raise AuthTokenError("Invalid or expired token") from exc
    if payload.get("type") != expected_type or "sub" not in payload:
        raise AuthTokenError("Invalid token")
    return payload


def _decode_token(token: str, expected_type: str) -> str:
    return _decode_token_payload(token, expected_type)["sub"]


def create_access_token(user_id: str) -> str:
    return _create_token(user_id, "access", settings.jwt_access_token_expire_minutes)


def decode_access_token(token: str) -> str:
    return _decode_token(token, "access")


def decode_access_token_claims(token: str) -> tuple[str, int]:
    """Returns (user_id, issued_at) so callers can reject tokens issued before a session revocation."""
    payload = _decode_token_payload(token, "access")
    return payload["sub"], int(payload.get("iat", 0))


def create_reset_token(user_id: str) -> str:
    return _create_token(user_id, "reset", settings.jwt_reset_token_expire_minutes)


def decode_reset_token(token: str) -> str:
    return _decode_token(token, "reset")


def create_sso_exchange_token(user_id: str) -> str:
    """Short-lived, one-shot-in-spirit token carried in the SSO redirect URL back to the
    frontend, which immediately exchanges it for a real access token. Keeps the long-lived
    access token out of the URL (browser history, referrer headers, server logs)."""
    return _create_token(user_id, "sso_exchange", settings.jwt_sso_exchange_token_expire_minutes)


def decode_sso_exchange_token(token: str) -> str:
    return _decode_token(token, "sso_exchange")

    normalized = email.strip().lower()
    user = db.scalar(select(User).where(User.email == normalized))
    if not user or not user.password_hash:

    if not verify_password(password, user.password_hash):

    return user

    normalized = email.strip().lower()
    user = db.scalar(select(User).where(User.email == normalized))

    user_id = decode_reset_token(token)
    user = db.get(User, user_id)
    if not user:
        raise AuthTokenError("Invalid or expired token")
    user.password_hash = hash_password(new_password)
    db.add(user)
    db.commit()

# Free viewers see the overview plus this many timeline sections; everything else is counted, not sent.
ANALYSIS_PREVIEW_SECTIONS = 1


def analysis_for_viewer(analysis: dict[str, Any] | None, is_pro: bool) -> tuple[dict[str, Any] | None, AnalysisLock | None]:
    """Return the analysis a viewer may see: all of it for Pro, otherwise a preview plus locked counts."""
    if not analysis or is_pro:
        return analysis, None

    def items(key: str) -> list[Any]:
        value = analysis.get(key)
        return value if isinstance(value, list) else []

    timeline = items("timeline")
    preview = {
        "overview": analysis.get("overview") or "",
        "timeline": timeline[:ANALYSIS_PREVIEW_SECTIONS],
        "duration_seconds": analysis.get("duration_seconds"),
    }
    lock = AnalysisLock(
        hidden_sections=max(0, len(timeline) - ANALYSIS_PREVIEW_SECTIONS),
        hidden_questions=len(items("questions_and_answers")),
        hidden_decisions=len(items("decisions")),
        hidden_action_items=len(items("action_items")),
        hidden_terms=len(items("terms")),
    )
    return preview, lock

STALE_JOB_REASON = "Processing was interrupted before it finished. Please retry."


def fail_stale_jobs(db: Session, now: datetime | None = None) -> int:
    """Fail jobs a lost worker left behind, so clients stop polling and the user can retry.

    A job is stale when it has been "processing" longer than the worker's hard time limit
    (the worker that owned it is gone) or "queued" longer than stale_queued_job_seconds.
    """
    now = now or datetime.now(timezone.utc)
    processing_cutoff = now - timedelta(seconds=settings.job_hard_time_limit_seconds + 300)
    queued_cutoff = now - timedelta(seconds=settings.stale_queued_job_seconds)
    stale_ids = db.scalars(
        select(Job.id).where(
            or_(
                (Job.status == "processing") & (Job.processing_started_at < processing_cutoff),
                (Job.status == "queued") & (Job.updated_at < queued_cutoff),
            )
        )
    ).all()
    failed = 0
    for job_id in stale_ids:
        # Re-check the status in the UPDATE so a job that finished meanwhile is left alone.
        changed = db.execute(
            update(Job)
            .where(Job.id == job_id, Job.status.in_(("processing", "queued")))
            .values(status="failed", summary="Processing failed. Please retry.", error_message=STALE_JOB_REASON, processing_completed_at=now)
        )
        failed += changed.rowcount
    db.commit()
    return failed


def prepare_job_retry(db: Session, job: Job) -> Job:
    """Return a failed workspace job to the queue without exposing stale results."""
    if job.status != "failed":
        raise HTTPException(status_code=409, detail="Only failed jobs can be retried")
    if job.is_pipeline_run:
        raise HTTPException(status_code=400, detail="Pipeline jobs must be restarted from the pipeline endpoint")
    changed = db.execute(
        update(Job)
        .where(Job.id == job.id, Job.status == "failed")
        .values(
            status="queued",
            processing_stage=0,
            summary="Retry queued. Worker will start processing shortly.",
            error_message=None,
            processing_started_at=None,
            processing_completed_at=None,
            stage_events_json="[]",
            analysis_json=None,
            key_points_json="[]",
            pdf_asset_key=None,
            transcript_text=None,
            transcript_segments_json="[]",
            media_duration_seconds=None,
            transcription_model=None,
            summary_model=None,
        )
    )
    if changed.rowcount != 1:
        db.rollback()
        raise HTTPException(status_code=409, detail="This job is already queued for retry")
    db.commit()
    db.refresh(job)
    return job


def set_action_item_completed(db: Session, job: Job, index: int, completed: bool) -> Job:
    """Tick/untick an action item by its position in the combined LLM + custom list."""
    total = len(get_job_action_items(job))
    if index < 0 or index >= total:
        raise HTTPException(status_code=404, detail="Action item not found")

    try:
        done = json.loads(job.completed_action_items_json or "[]")
    except ValueError:
        done = []
    indices = {int(value) for value in done if isinstance(value, int)} if isinstance(done, list) else set()

    if completed:
        indices.add(index)
    else:
        indices.discard(index)

    job.completed_action_items_json = json.dumps(sorted(indices))
    db.add(job)
    db.commit()
    db.refresh(job)

def _format_timestamp(seconds: object) -> str:
    total_seconds = max(0, int(seconds or 0))

def _wrap_text(text: str, max_chars: int) -> list[str]:
    words = text.split()
    if not words:
        return [""]


    lines: list[str] = []
    current = words[0]
    for word in words[1:]:
        candidate = f"{current} {word}"
        if len(candidate) <= max_chars:
            current = candidate
        else:
            lines.append(current)
            current = word
    lines.append(current)
    return lines


class _DetailedReport:

        self.c.setFont(BOLD_FONT, 11)
        self.c.drawString(MARGIN, PAGE_HEIGHT - 29, "FrameNote Video Report (continued)")
        self.y = PAGE_HEIGHT - 72

    def ensure(self, needed: float) -> None:
        if self.y - needed < BOTTOM_LIMIT:

    def save(self) -> None:

    def section(self, title: str) -> None:

def _item_text(item: Any) -> str:
    if isinstance(item, dict):
        return str(item.get("title") or item.get("text") or item)
    return str(item)


def _normalized(text: str) -> str:
    return " ".join(str(text or "").lower().split())


def _short_paragraphs(text: str) -> list[str]:
    cleaned = " ".join(str(text or "").split())
    if not cleaned:
        return [""]
    sentences: list[str] = []
    current = ""
    for char in cleaned:
        current += char
        if char in ".!?" and len(current.strip()) > 2:
            sentences.append(current.strip())
            current = ""
    if current.strip():
        sentences.append(current.strip())
    return [" ".join(sentences[index:index + 2]) for index in range(0, len(sentences), 2)]


def _wrap_width(text: str, font: str, size: float, max_width: float) -> list[str]:
    words = " ".join(str(text or "").split()).split(" ")
    if not words or words == [""]:
        return [""]
    lines: list[str] = []
    current = words[0]
    for word in words[1:]:
        candidate = f"{current} {word}"
        if stringWidth(candidate, font, size) <= max_width:
            current = candidate
        else:
            lines.append(current)
            current = word
    lines.append(current)
    return lines


def _truncate_width(text: str, font: str, size: float, max_width: float) -> str:
    value = str(text or "")
    if stringWidth(value, font, size) <= max_width:
        return value
    while value and stringWidth(f"{value}...", font, size) > max_width:
        value = value[:-1]
    return f"{value}..."


def _frame_path(frame_url: Any) -> Path | None:
    if not isinstance(frame_url, str) or "/assets/" not in frame_url:
        return None
    try:
        return resolve_processed_asset_path(frame_url.split("/assets/", 1)[1])
    except Exception:
        return None


def _clock(seconds: Any) -> str:
    total = max(0, int(float(seconds or 0)))
    minutes, secs = divmod(total, 60)
    return f"{minutes}:{secs:02d}"


def _time_range(start: Any, end: Any) -> str:
    start_label = _clock(start)
    end_label = _clock(end)
    return start_label if start_label == end_label else f"{start_label} - {end_label}"


def _duration_label(seconds: Any) -> str:
    total = int(float(seconds or 0))
    if total <= 0:
        return "Unknown"
    minutes, secs = divmod(total, 60)
    return f"{minutes} min {secs:02d} sec"

Powers the Settings tier card, the sidebar quota meter, and the Pricing page's "current plan" state.

from calendar import monthrange
from datetime import datetime, timedelta, timezone

from sqlalchemy import select

TIER_QUOTAS: dict[str, dict[str, float | None]] = {
    "free": {"hours": 1.0, "storage_gb": 0.5, "price": 0, "max_video_minutes": 30},
    "pro": {"hours": 15.0, "storage_gb": 20.0, "price": 12, "max_video_minutes": 120},
}
# YouTube notes use published captions (no transcription cost), so they are counted, not timed.
FREE_YOUTUBE_NOTES_PER_MONTH = 3

    "free": "Free Starter",
    "pro": "Solo Pro",

def _billing_period_start(now: datetime) -> datetime:
    return now.replace(day=1, hour=0, minute=0, second=0, microsecond=0)


def _next_billing_reset(now: datetime) -> datetime:
    days_in_month = monthrange(now.year, now.month)[1]
    return _billing_period_start(now) + timedelta(days=days_in_month)


def _job_duration_seconds(job: Job) -> float:
    """Media runtime for a job, preferring the analysis duration and falling back to transcript spans."""
    if job.media_duration_seconds and job.media_duration_seconds > 0:
        return float(job.media_duration_seconds)
    if job.analysis_json:
        try:
            analysis = json.loads(job.analysis_json)
        except ValueError:
            analysis = None
        if isinstance(analysis, dict):
            duration = analysis.get("duration_seconds")
            if isinstance(duration, (int, float)) and duration > 0:
                return float(duration)

    try:
        segments = json.loads(job.transcript_segments_json or "[]")
    except ValueError:
        segments = []
    if isinstance(segments, list) and segments:
        ends = [float(entry.get("end") or 0) for entry in segments if isinstance(entry, dict)]
        if ends:
            return max(ends)
    return 0.0


def job_insight_count(job: Job) -> int:
    """How many discrete insights were extracted - the number shown on each History row."""
    total = 0
    try:
        total += len(json.loads(job.key_points_json or "[]"))
    except ValueError:
        pass

    if job.analysis_json:
        try:
            analysis = json.loads(job.analysis_json)
        except ValueError:
            analysis = None
        if isinstance(analysis, dict):
            for key in ("headlines", "decisions", "action_items", "questions_and_answers"):
                value = analysis.get(key)
                if isinstance(value, list):
                    total += len(value)

    try:
        total += len(json.loads(job.custom_action_items_json or "[]"))
    except ValueError:
        pass
    return total


def job_duration_seconds(job: Job) -> int | None:
    seconds = _job_duration_seconds(job)
    return int(seconds) if seconds > 0 else None


def _upload_bytes(job: Job) -> int:
    if not job.upload_object_key:
        return 0
    try:
        path = Path(app_settings.local_upload_dir) / job.upload_object_key
        return path.stat().st_size if path.is_file() else 0
    except OSError:
        return 0


def _average_turn_ratio(jobs: list[Job]) -> float:
    """Measured throughput: pipeline wall-clock divided by media runtime, averaged over completed jobs.

    Labelled "Average turn ratio" in the UI, where lower is faster (0.2x = a 10-minute video
    processed in 2 minutes). Jobs recorded before timing was instrumented are skipped, so this
    returns 0 until at least one job has run end-to-end with both timestamps.
    """
    ratios: list[float] = []
    for job in jobs:
        if job.status != "completed" or not job.processing_started_at or not job.processing_completed_at:
            continue
        media_seconds = _job_duration_seconds(job)
        if media_seconds <= 0:
            continue
        started = job.processing_started_at
        finished = job.processing_completed_at
        # SQLite hands back naive datetimes; assume they are already UTC.
        if started.tzinfo is None:
            started = started.replace(tzinfo=timezone.utc)
        if finished.tzinfo is None:
            finished = finished.replace(tzinfo=timezone.utc)
        elapsed = (finished - started).total_seconds()
        if elapsed <= 0:
            continue
        ratios.append(elapsed / media_seconds)

    if not ratios:
        return 0.0
    # Floor at 0.01 so a very fast run stays distinguishable from "nothing measured yet" (0.0).
    return max(0.01, round(sum(ratios) / len(ratios), 2))


def _meter(used: float, limit: float | None, unit: str) -> UsageMeter:
    if limit is None or limit <= 0:
        return UsageMeter(used=round(used, 1), limit=None, unit=unit, percent=0)
    percent = min(100.0, round((used / limit) * 100, 1))
    return UsageMeter(used=round(used, 1), limit=limit, unit=unit, percent=percent)


def build_usage_summary(db: Session, user: User) -> UsageSummaryResponse:
    subscription = get_user_subscription(db=db, user_id=user.id)
    tier = subscription.tier if subscription.tier in TIER_QUOTAS else "free"
    quota = TIER_QUOTAS[tier]

    now = datetime.now(timezone.utc)
    period_start = _billing_period_start(now)

    jobs = list(db.scalars(select(Job).where(Job.owner_id == user.id)).all())

    period_seconds = 0.0
    total_bytes = 0
    videos_this_period = 0
    insights_total = 0

    for job in jobs:
        total_bytes += _upload_bytes(job)
        insights_total += job_insight_count(job)

        created = job.created_at
        if created is not None:
            # SQLite hands back naive datetimes; assume they are already UTC.
            if created.tzinfo is None:
                created = created.replace(tzinfo=timezone.utc)
            if created >= period_start:
                videos_this_period += 1
                period_seconds += _job_duration_seconds(job)

    hours_used = period_seconds / 3600
    storage_used_gb = total_bytes / (1024**3)

    avg_turn_ratio = _average_turn_ratio(jobs)

    reset_at = _next_billing_reset(now)
    resets_in_days = max(0, (reset_at - now).days)

    return UsageSummaryResponse(
        tier=tier,
        plan_label=TIER_LABELS.get(tier, "Free Starter"),
        plan_price_monthly=int(quota["price"]) if quota["price"] is not None else None,
        subscription_status=subscription.status,
        transcription_hours=_meter(hours_used, quota["hours"], "hrs"),
        storage_gb=_meter(storage_used_gb, quota["storage_gb"], "GB"),
        videos_processed=videos_this_period,
        insights_extracted=insights_total,
        avg_turn_ratio=avg_turn_ratio,
        resets_in_days=resets_in_days,
        renews_on=reset_at,
    )


def ensure_job_creation_allowed(db: Session, user: User, source_type: str) -> None:
    """Apply the published monthly job limits before queueing new processing work."""
    subscription = get_user_subscription(db=db, user_id=user.id)
    tier = subscription.tier if subscription.status.lower() == "active" else "free"
    now = datetime.now(timezone.utc)
    period_start = _billing_period_start(now)
    jobs = list(db.scalars(select(Job).where(Job.owner_id == user.id, Job.created_at >= period_start)).all())
    # A failed job may be retried, so it must not consume a separate monthly slot.
    jobs = [job for job in jobs if job.status != "failed"]

    if tier != "pro" and source_type == "youtube":
        used = sum(job.source_type == "youtube" for job in jobs)
        if used >= FREE_YOUTUBE_NOTES_PER_MONTH:
            raise HTTPException(
                status_code=403,
                detail=f"Free Starter includes {FREE_YOUTUBE_NOTES_PER_MONTH} YouTube notes per month. Upgrade or wait for the monthly reset.",
            )
        return

    quota_hours = _quota(tier, "hours")
    used_seconds = sum(_job_duration_seconds(job) for job in jobs if job.source_type in {"upload", "url"})
    if used_seconds >= quota_hours * 3600:
        upgrade_hint = "Upgrade to Solo Pro or wait" if tier != "pro" else "Please wait"
        raise HTTPException(
            status_code=403,
            detail=f"Your {_hours_label(quota_hours)} of monthly video are used. {upgrade_hint} for the monthly reset.",
        )


def _quota(tier: str, key: str) -> float:
    return float(TIER_QUOTAS.get(tier, TIER_QUOTAS["free"])[key] or 0)


def _hours_label(hours: float) -> str:
    return f"{hours:g} hour" + ("" if hours == 1 else "s")


def reserve_media_duration(db: Session, job: Job, duration_seconds: int | None) -> None:
    """Check runtime before transcription, then reserve it for concurrent submissions."""
    if not duration_seconds or job.source_type == "youtube":
        return
    user = db.get(User, job.owner_id)
    if user is None:
        raise HTTPException(status_code=404, detail="Account not found")
    subscription = get_user_subscription(db=db, user_id=user.id)
    tier = subscription.tier if subscription.status.lower() == "active" else "free"
    max_minutes = int(_quota(tier, "max_video_minutes"))
    if duration_seconds > max_minutes * 60:
        raise HTTPException(status_code=403, detail=f"This video exceeds the {max_minutes}-minute limit for your plan.")

    period_start = _billing_period_start(datetime.now(timezone.utc))
    other_jobs = db.scalars(select(Job).where(Job.owner_id == user.id, Job.created_at >= period_start, Job.id != job.id)).all()
    used_seconds = sum(
        _job_duration_seconds(other)
        for other in other_jobs
        if other.status != "failed" and other.source_type in {"upload", "url"}
    )
    monthly_limit = _quota(tier, "hours") * 3600
    if used_seconds + duration_seconds > monthly_limit:
        raise HTTPException(status_code=403, detail="This video would exceed your monthly transcription allowance. Try a shorter video or wait for the reset.")
    job.media_duration_seconds = duration_seconds
    db.add(job)
    db.commit()

def ask_video_question(
    db: Session,
    job: Job,
    user: User,
    question: str,
    contexts: list[VideoChatContext] | None = None,
) -> VideoChatAnswerResponse:
    clean_question = " ".join(question.split())
    if len(clean_question) < 2:
        raise HTTPException(status_code=422, detail="Enter a question about this video.")
    if job.status != "completed":
        raise HTTPException(status_code=409, detail="Wait for video processing to finish before asking questions.")
    if not (job.transcript_text or "").strip():
        raise HTTPException(status_code=409, detail="This video does not have a saved transcript to answer from.")
    if not ai_is_configured():
        raise HTTPException(status_code=503, detail="AI chat is not configured on this server yet.")

    usage_before = _usage(db=db, user=user, job_id=job.id)
    if usage_before.remaining_this_month <= 0:
        raise HTTPException(
            status_code=429,
            detail=f"You have used this month's {usage_before.monthly_limit} Ask this video questions.",
        )
    if usage_before.per_video_limit is not None and usage_before.used_for_video >= usage_before.per_video_limit:
        raise HTTPException(
            status_code=429,
            detail=f"Free accounts can ask {usage_before.per_video_limit} questions per video. Upgrade to continue.",
        )
    if _tokens_used_this_month(db) >= max(1, settings.video_chat_monthly_token_budget):
        raise HTTPException(
            status_code=503,
            detail="Ask this video has reached its service budget for this month. Please try again after the reset.",
        )

    clean_contexts = _clean_contexts(contexts or [])
    prior_messages = list(
        db.scalars(
            select(ChatMessage)
            .where(ChatMessage.job_id == job.id, ChatMessage.user_id == user.id)
            .order_by(ChatMessage.created_at.desc(), ChatMessage.id.desc())
            .limit(6)
        ).all()
    )
    prior_messages.reverse()
    relevance_query = " ".join(
        [
            clean_question,
            *(item.content for item in prior_messages[-2:]),
            *(f"{item.label} {item.selected_text or ''}" for item in clean_contexts),
        ]
    )
    excerpts = _select_excerpts(job=job, question=relevance_query)
    # Chat must not reveal analysis the viewer's plan only previews.
    visible_analysis, _ = analysis_for_viewer(get_job_analysis(job), is_pro=user_is_pro(db, user.id))
    raw_answer, input_tokens, output_tokens = _generate_answer(
        job=job,
        question=clean_question,
        excerpts=excerpts,
        prior_messages=prior_messages,
        contexts=clean_contexts,
        analysis=visible_analysis or {},
    )
    answer, citation_ids = _parse_model_answer(raw_answer)

    citation_map = {f"C{index}": excerpt for index, excerpt in enumerate(excerpts, start=1)}
    citations = [_citation(citation_map[citation_id]) for citation_id in citation_ids if citation_id in citation_map]
    now = datetime.now(timezone.utc)
    user_message = ChatMessage(
        job_id=job.id,
        user_id=user.id,
        role="user",
        content=clean_question,
        contexts_json=json.dumps([item.model_dump() for item in clean_contexts]),
        created_at=now,
    )
    assistant_message = ChatMessage(
        job_id=job.id,
        user_id=user.id,
        role="assistant",
        content=answer,
        citations_json=json.dumps([item.model_dump() for item in citations]),
        input_tokens=input_tokens,
        output_tokens=output_tokens,
        created_at=now + timedelta(microseconds=1),
    )

    db.commit()
    db.refresh(user_message)
    db.refresh(assistant_message)

    return VideoChatAnswerResponse(
        user_message=_to_message(user_message),
        assistant_message=_to_message(assistant_message),

    )

            )
        )
        or 0
    )
    used_video = int(
        db.scalar(
            select(func.count(ChatMessage.id)).where(
                ChatMessage.user_id == user.id,
                ChatMessage.job_id == job_id,
                ChatMessage.role == "user",
            )
        )
        or 0
    )
    return VideoChatUsage(
        used_this_month=used_month,
        monthly_limit=monthly_limit,
        remaining_this_month=max(0, monthly_limit - used_month),
        used_for_video=used_video,
        per_video_limit=per_video_limit,
    )


def _tokens_used_this_month(db: Session) -> int:
    now = datetime.now(timezone.utc)
    period_start = now.replace(day=1, hour=0, minute=0, second=0, microsecond=0)
    return int(
        db.scalar(
            select(func.coalesce(func.sum(ChatMessage.input_tokens + ChatMessage.output_tokens), 0)).where(
                ChatMessage.role == "assistant",
                ChatMessage.created_at >= period_start,
            )
        )
        or 0
    )


def _to_message(message: ChatMessage) -> VideoChatMessage:
    try:
        raw_citations = json.loads(message.citations_json or "[]")
    except ValueError:
        raw_citations = []
    citations: list[VideoChatCitation] = []
    if isinstance(raw_citations, list):
        for item in raw_citations:
            try:
                citations.append(VideoChatCitation.model_validate(item))
            except (TypeError, ValueError):
                continue
    try:
        raw_contexts = json.loads(message.contexts_json or "[]")
    except ValueError:
        raw_contexts = []
    contexts: list[VideoChatContext] = []
    if isinstance(raw_contexts, list):
        for item in raw_contexts:
            try:
                contexts.append(VideoChatContext.model_validate(item))
            except (TypeError, ValueError):
                continue
    return VideoChatMessage(
        message_id=message.id,
        role="assistant" if message.role == "assistant" else "user",
        content=message.content,
        citations=citations,
        contexts=contexts,
        created_at=message.created_at,
    )


def _clean_contexts(contexts: list[VideoChatContext]) -> list[VideoChatContext]:
    cleaned: list[VideoChatContext] = []
    seen: set[tuple[str, str]] = set()
    for context in contexts[:8]:
        if context.context_id not in _CONTEXT_LABELS:
            continue
        selected_text = " ".join((context.selected_text or "").split())[:1200] or None
        identity = (context.context_id, selected_text or "")
        if identity in seen:
            continue
        cleaned.append(
            VideoChatContext(
                context_id=context.context_id,
                label=_CONTEXT_LABELS[context.context_id],
                selected_text=selected_text,
            )
        )
        seen.add(identity)
    return cleaned


def _select_excerpts(job: Job, question: str) -> list[_Excerpt]:
    excerpts = _transcript_excerpts(job)
    if not excerpts:
        excerpts = [_Excerpt(start_seconds=0, end_seconds=0, text=(job.transcript_text or "")[:4000])]

    context_limit = max(4000, settings.video_chat_context_chars)
    if sum(len(item.text) for item in excerpts) <= context_limit:
        return excerpts

    terms = _terms(question)
    scored = [(_score(item.text, terms), index, item) for index, item in enumerate(excerpts)]
    positive = [item for item in scored if item[0] > 0]
    if positive:
        selected_indices: set[int] = set()
        for _, index, _ in sorted(positive, key=lambda row: (-row[0], row[1]))[:12]:
            selected_indices.update({max(0, index - 1), index, min(len(excerpts) - 1, index + 1)})
    else:
        sample_count = min(16, len(excerpts))
        selected_indices = {
            round(index * (len(excerpts) - 1) / max(1, sample_count - 1)) for index in range(sample_count)
        }

    selected: list[_Excerpt] = []
    chars = 0
    for index in sorted(selected_indices):
        item = excerpts[index]
        if selected and chars + len(item.text) > context_limit:
            break
        selected.append(item)
        chars += len(item.text)
    return selected


def _transcript_excerpts(job: Job) -> list[_Excerpt]:
    try:
        raw_segments = json.loads(job.transcript_segments_json or "[]")
    except ValueError:
        raw_segments = []
    if not isinstance(raw_segments, list):
        return []

    excerpts: list[_Excerpt] = []
    chunk_text: list[str] = []
    chunk_start = 0
    chunk_end = 0
    for raw in raw_segments:
        if not isinstance(raw, dict):
            continue
        text = str(raw.get("text") or "").strip()
        if not text:
            continue
        start = _seconds(raw.get("start"))
        end = max(start, _seconds(raw.get("end")))
        speaker = str(raw.get("speaker") or "").strip()
        line = f"{speaker}: {text}" if speaker and not text.startswith(f"{speaker}:") else text
        if chunk_text and (sum(len(value) for value in chunk_text) + len(line) > 900 or end - chunk_start > 90):
            excerpts.append(_Excerpt(chunk_start, chunk_end, " ".join(chunk_text)))
            chunk_text = []
        if not chunk_text:
            chunk_start = start
        chunk_end = end
        chunk_text.append(line)
    if chunk_text:
        excerpts.append(_Excerpt(chunk_start, chunk_end, " ".join(chunk_text)))
    return excerpts


def _terms(text: str) -> set[str]:
    return {
        term
        for term in re.findall(r"[a-z0-9]+", text.lower())
        if len(term) >= 3 and term not in _STOP_WORDS
    }


def _score(text: str, terms: set[str]) -> int:
    lowered = text.lower()
    return sum(lowered.count(term) for term in terms)


def _seconds(value: Any) -> int:
    try:
        return max(0, int(float(value or 0)))
    except (TypeError, ValueError):
        return 0


def _generate_answer(
    job: Job,
    question: str,
    excerpts: list[_Excerpt],
    prior_messages: list[ChatMessage],
    contexts: list[VideoChatContext],
    analysis: dict[str, Any] | None = None,
) -> tuple[str, int, int]:
    source_lines = [
        f"C{index} [{_clock(item.start_seconds)}-{_clock(item.end_seconds)}] {item.text}"
        for index, item in enumerate(excerpts, start=1)
    ]
    analysis = analysis or {}
    analysis_text = json.dumps(analysis, ensure_ascii=True)[:8000] if analysis else ""
    history = "\n".join(f"{item.role}: {item.content[:1000]}" for item in prior_messages)
    focus_context = _build_focus_context(job=job, contexts=contexts, analysis=analysis)
    user_content = (
        f"VIDEO SUMMARY:\n{job.summary[:4000]}\n\n"
        f"VIDEO ANALYSIS:\n{analysis_text}\n\n"
        f"RECENT CONVERSATION:\n{history or '(none)'}\n\n"
        f"USER-ATTACHED PAGE CONTEXT:\n{focus_context or '(none; answer from the whole video)'}\n\n"
        f"TIMESTAMPED EXCERPTS:\n{chr(10).join(source_lines)}\n\n"
        f"QUESTION:\n{question}"
    )

    azure_configured = False
    if settings.temp_providers_enabled:
        try:
            from app.services.temp_azure_llm import chat_json_with_temp_azure, is_configured

            azure_configured = is_configured()
            if azure_configured:
                content = chat_json_with_temp_azure(system_prompt=_SYSTEM_PROMPT, user_content=user_content)
                if content:
                    return content, max(1, len(user_content) // 4), max(1, len(content) // 4)
        except ImportError:
            pass

    if settings.openai_api_key:
        try:
            client = OpenAI(api_key=settings.openai_api_key, timeout=60.0)
            response = client.chat.completions.create(
                model=settings.openai_video_chat_model,
                response_format={"type": "json_object"},
                max_tokens=max(100, settings.video_chat_max_output_tokens),
                messages=[
                    {"role": "system", "content": _SYSTEM_PROMPT},
                    {"role": "user", "content": user_content},
                ],
            )
            usage = response.usage
            return (
                response.choices[0].message.content or "{}",
                int(getattr(usage, "prompt_tokens", 0) or 0),
                int(getattr(usage, "completion_tokens", 0) or 0),
            )
        except Exception as exc:
            logger.exception("OpenAI video chat request failed")
            raise HTTPException(status_code=502, detail="The AI assistant could not answer right now. Try again.") from exc

    if settings.gemini_api_key:
        try:
            import google.generativeai as genai

            genai.configure(api_key=settings.gemini_api_key)
            model = genai.GenerativeModel(settings.gemini_model)
            response = model.generate_content(
                f"{_SYSTEM_PROMPT}\n\n{user_content}",
                generation_config={
                    "response_mime_type": "application/json",
                    "max_output_tokens": max(100, settings.video_chat_max_output_tokens),
                },
            )
            usage = getattr(response, "usage_metadata", None)
            return (
                getattr(response, "text", None) or "{}",
                int(getattr(usage, "prompt_token_count", 0) or 0),
                int(getattr(usage, "candidates_token_count", 0) or 0),
            )
        except Exception as exc:
            logger.exception("Gemini video chat request failed")
            raise HTTPException(status_code=502, detail="The AI assistant could not answer right now. Try again.") from exc

    if azure_configured:
        raise HTTPException(status_code=502, detail="The AI assistant could not answer right now. Try again.")
    raise HTTPException(status_code=503, detail="AI chat is not configured on this server yet.")


def _build_focus_context(job: Job, contexts: list[VideoChatContext], analysis: dict[str, Any] | None = None) -> str:
    if not contexts:
        return ""
    analysis = analysis or {}
    try:
        key_points = json.loads(job.key_points_json or "[]")
    except ValueError:
        key_points = []
    try:
        custom_actions = json.loads(job.custom_action_items_json or "[]")
    except ValueError:
        custom_actions = []

    blocks: list[str] = []
    for context in contexts:
        section: Any = None
        if context.context_id == "summary":
            section = job.summary
        elif context.context_id in {"highlights", "chapters", "key-moments"}:
            section = key_points
        elif context.context_id == "action-items":
            generated = analysis.get("action_items", []) if isinstance(analysis, dict) else []
            section = {"generated": generated, "custom": custom_actions}
        elif context.context_id == "detailed-notes":
            section = {
                key: analysis.get(key, [])
                for key in ("timeline", "questions_and_answers", "decisions")
            } if isinstance(analysis, dict) else {}
        elif context.context_id == "speakers":
            try:
                speaker_airtime = json.loads(job.speaker_airtime_json or "[]")
            except ValueError:
                speaker_airtime = []
            section = {
                "participants": analysis.get("participants", {}) if isinstance(analysis, dict) else {},
                "speaker_airtime": speaker_airtime,
            }
        elif context.context_id == "raw-transcript":
            section = "Use the timestamped transcript excerpts below."
        elif context.context_id == "glossary":
            section = analysis.get("terms", []) if isinstance(analysis, dict) else []

        rendered = section if isinstance(section, str) else json.dumps(section, ensure_ascii=True)
        selected = f"\nSelected text: {context.selected_text}" if context.selected_text else ""
        blocks.append(f"[{context.label}]\n{str(rendered)[:6000]}{selected}")
    return "\n\n".join(blocks)


def _parse_model_answer(content: str) -> tuple[str, list[str]]:
    cleaned = content.strip()
    if cleaned.startswith("```"):
        cleaned = re.sub(r"^```(?:json)?\s*|\s*```$", "", cleaned, flags=re.IGNORECASE)
    try:
        payload = json.loads(cleaned)
    except (TypeError, ValueError) as exc:
        raise HTTPException(status_code=502, detail="The AI assistant returned an unreadable response. Try again.") from exc
    answer = str(payload.get("answer") or "").strip() if isinstance(payload, dict) else ""
    raw_ids = payload.get("citation_ids") if isinstance(payload, dict) else []
    citation_ids = [str(value).upper() for value in raw_ids if isinstance(value, str)] if isinstance(raw_ids, list) else []
    if not answer:
        raise HTTPException(status_code=502, detail="The AI assistant returned an empty response. Try again.")
    return answer, list(dict.fromkeys(citation_ids))[:6]


def _citation(excerpt: _Excerpt) -> VideoChatCitation:
    compact = " ".join(excerpt.text.split())
    return VideoChatCitation(
        timestamp_seconds=excerpt.start_seconds,
        label=_clock(excerpt.start_seconds),
        excerpt=compact[:220] + ("…" if len(compact) > 220 else ""),
    )


def _clock(total_seconds: int) -> str:
    hours, remainder = divmod(max(0, total_seconds), 3600)
    minutes, seconds = divmod(remainder, 60)
    return f"{hours:02d}:{minutes:02d}:{seconds:02d}" if hours else f"{minutes:02d}:{seconds:02d}"

def _claim_job(db, job_id: str):
    """Load the job and mark it processing, or return None if a redelivered task already finished it."""
    job = get_job_or_404(db=db, job_id=job_id)

        return None

        reason = TIMEOUT_REASON
    else:
        logger.exception("Job %s failed", job_id)
        reason = str(exc)
    try:
        db.rollback()
        job = get_job_or_404(db=db, job_id=job_id)
        mark_job_failed(db=db, job=job, reason=reason)
    except Exception:
        logger.exception("Could not mark job %s as failed", job_id)

function toClock(totalSeconds: number): string {
  const safeSeconds = Math.max(0, Math.round(totalSeconds));
  const hours = Math.floor(safeSeconds / 3600);
  const minutes = Math.floor((safeSeconds % 3600) / 60);
  const seconds = safeSeconds % 60;
  if (hours > 0) {
    return `${String(hours).padStart(2, "0")}:${String(minutes).padStart(2, "0")}:${String(seconds).padStart(2, "0")}`;
  }
  return `${String(minutes).padStart(2, "0")}:${String(seconds).padStart(2, "0")}`;
}

function speakerInitials(name: string): string {
  const words = name.trim().split(/\s+/).filter(Boolean);
  if (words.length === 0) {
    return "?";
  }
  if (words.length === 1) {
    return words[0].slice(0, 2).toUpperCase();
  }
  return `${words[0][0]}${words[words.length - 1][0]}`.toUpperCase();
}

function highlightMatches(text: string, query: string) {
  const trimmed = query.trim();
  if (!trimmed) {
    return text;
  }
  const escaped = trimmed.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
  const parts = text.split(new RegExp(`(${escaped})`, "gi"));
  return parts.map((part, index) =>
    part.toLowerCase() === trimmed.toLowerCase() ? (
      <mark key={index} className="rounded bg-state-warning/30 px-0.5 text-core-on-surface">
        {part}
      </mark>
    ) : (
      <span key={index}>{part}</span>
    )
  );
}

// Transcript import bakes "Speaker: " into segment.text; strip it since the speaker is shown separately.
function segmentDialogue(segment: TranscriptSegment): string {
  if (!segment.speaker) {
    return segment.text;
  }
  const prefix = `${segment.speaker}:`;
  return segment.text.startsWith(prefix) ? segment.text.slice(prefix.length).trimStart() : segment.text;
}

function jobTitle(job: JobCreateResponse | null): string {
  if (!job) {
    return "No note selected";
  }
  if (job.file_name) {
    return job.file_name.replace(/\.[a-z0-9]+$/i, "").replace(/[-_]+/g, " ");
  }
  if (job.source_url) {
    return job.source_url;
  }
  return `Note ${job.job_id.slice(0, 8)}`;
}

function formatRecordedDate(isoDate: string): string {
  const parsed = new Date(isoDate);
  if (Number.isNaN(parsed.getTime())) {
    return "Unknown date";
  }
  return parsed.toLocaleDateString(undefined, { month: "short", day: "numeric", year: "numeric" });
}

function readMinutes(job: JobCreateResponse | null): number {
  if (!job) {
    return 0;
  }
  const words = [job.summary, ...job.key_points.map((point) => `${point.title} ${point.description}`)]
    .join(" ")
    .trim()
    .split(/\s+/)
    .filter(Boolean).length;
  return Math.max(1, Math.round(words / 200));
}

    }, 400);

    setBusy(true);

      setResult({ ...result, pdf_url: generated.pdf_url });

    } finally {
      setBusy(false);

    setPlaybackSeconds(seconds);

      playerRef.current?.seekTo(seconds, true);
    } else if (videoRef.current) {
      videoRef.current.currentTime = seconds;
      void videoRef.current.play();
    }
    if (typeof window !== "undefined") {
      window.scrollTo({ top: 0, behavior: "smooth" });
    }
  }

    seekToSeconds(point.timestamp_seconds);
  }

    if (!result) {
      return;
    }
    const text = actionItemDraft.trim();
    if (!text) {
      return;
    }
    setActionItemSaving(true);
    setActionItemError(null);
    try {
      const updated = await addJobActionItem(result.job_id, text);
      setResult(updated);
      setHistory((prev) => prev.map((job) => (job.job_id === updated.job_id ? updated : job)));
      setActionItemDraft("");
      setAddActionItemOpen(false);
    } catch (submitError) {
      setActionItemError(submitError instanceof Error ? submitError.message : "Failed to add action item.");
    } finally {
      setActionItemSaving(false);
    }
  }

  async function toggleActionItem(index: number, completed: boolean) {
    if (!result) {
      return;
    }
    setPendingActionItems((prev) => ({ ...prev, [index]: completed }));
    try {
      const updated = await setJobActionItemCompleted(result.job_id, index, completed);
      setResult(updated);
      setHistory((prev) => prev.map((job) => (job.job_id === updated.job_id ? updated : job)));
    } catch {
      // Leave the server state as the source of truth; dropping the optimistic value reverts the tick.
    } finally {
      setPendingActionItems((prev) => {
        const next = { ...prev };
        delete next[index];
        return next;
      });
    }
  }

    }

  useEffect(() => {

    }

            <select aria-label="Project for this note" value={result.project_id ?? ""} onChange={(event) => void onAssignProject(event.target.value)} className="rounded-lg border border-core-outline-variant/30 bg-core-surface-container-lowest px-2 py-1 text-core-on-surface">
